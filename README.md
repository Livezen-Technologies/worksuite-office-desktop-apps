This repo contains the frontend of [WorkSuite Office](https://worksuitecloud.com), the desktop editors of
WorkSuite Cloud, which builds the program interface. WorkSuite Office is free and open-source software under the
AGPL v3.0, based on [ONLYOFFICE Desktop Editors](https://github.com/ONLYOFFICE/DesktopEditors)
© Ascensio System SIA (see `LICENSE`).

## Download

Get the latest version from [download.worksuitecloud.com](https://download.worksuitecloud.com):
Windows (.exe, .msi), macOS (Intel and Apple Silicon, .dmg) and Linux (.deb, .rpm, AppImage).

## Building from source

This repository (`desktop-apps`) is the frontend shell. It is built as a submodule of
[worksuite-office](https://github.com/Livezen-Technologies/worksuite-office); see its build README.
